
# Prometheus and Grafana Monitoring Project

## Overview

This project implements infrastructure monitoring using Prometheus and Grafana.

Prometheus collects metrics while Grafana provides dashboards for visualization.

## Objectives

- Monitor server resources
- Collect application metrics
- Create monitoring dashboards
- Configure alerts
- Understand observability

## Technologies Used

- Prometheus
- Grafana
- Docker
- Linux
- Node Exporter
