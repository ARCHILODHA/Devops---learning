# Git Clone

Git clone is used to create a local copy of an existing Git repository.

## Basic Command

```bash
git clone https://github.com/user/project.git
Clone with Custom Directory
git clone https://github.com/user/project.git my-project
Clone a Specific Branch
git clone -b develop https://github.com/user/project.git
Clone Using SSH
git clone git@github.com:user/project.git
