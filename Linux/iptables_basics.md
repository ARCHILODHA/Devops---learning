
# Linux iptables Basics

## Introduction
iptables is a Linux command-line utility used to configure IPv4 packet filtering rules.

It helps administrators control network traffic.

## Main Concepts

- Tables: Organize firewall functionality.
- Chains: Define where packets are processed.
- Rules: Specify matching conditions and actions.
- Targets: Define what happens to matching packets.

## Common Tables
- filter: Packet filtering.
- nat: Network address translation.
- mangle: Packet modification.

## Common Chains
- INPUT: Incoming packets for the local system.
- OUTPUT: Packets generated by the local system.
- FORWARD: Packets routed through the system.
