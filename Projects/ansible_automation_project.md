
# Ansible Server Automation Project

## Overview

This project demonstrates infrastructure and server configuration automation using Ansible.

Ansible allows administrators and DevOps engineers to configure multiple servers using reusable playbooks.

## Objectives

- Automate server configuration
- Install packages automatically
- Manage services
- Configure multiple servers
- Understand Infrastructure as Code

## Technologies Used

- Ansible
- Linux
- YAML
- SSH
- Ubuntu
