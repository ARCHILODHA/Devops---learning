
# Helm Kubernetes Deployment Project

## Overview

This project demonstrates deploying applications to Kubernetes using Helm charts.

Helm is a package manager for Kubernetes that simplifies application deployment and configuration.

## Objectives

- Understand Helm architecture
- Create a Helm chart
- Deploy applications to Kubernetes
- Manage configuration values
- Upgrade and rollback deployments

## Technologies Used

- Kubernetes
- Helm
- Docker
- YAML
