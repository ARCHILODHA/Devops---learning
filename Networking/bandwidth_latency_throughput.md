# Bandwidth, Latency and Throughput

## Bandwidth

Bandwidth is the maximum amount of data that can theoretically be transmitted over a network connection in a given amount of time.

It is commonly measured in:

bps
Kbps
Mbps
Gbps

Example:

100 Mbps

## Latency

Latency is the time taken for data to travel from one point to another.

It is commonly measured in milliseconds.

Example:

20 ms

Lower latency generally means faster response time.

## Throughput

Throughput is the actual amount of data successfully transferred over a network during a period of time.

For example:

Bandwidth = 100 Mbps
Actual throughput = 85 Mbps

The actual throughput can be lower because of:

- Network congestion
- Protocol overhead
- Packet loss
- Hardware limitations
- Network conditions

## Comparison

| Term | Meaning |
|---|---|
| Bandwidth | Maximum capacity |
| Throughput | Actual data transfer |
| Latency | Delay |

## Simple Example

Imagine a highway:

Bandwidth = Number of lanes
Throughput = Cars actually moving
Latency = Travel time

## Key Point

A high-bandwidth network does not necessarily have low latency.
