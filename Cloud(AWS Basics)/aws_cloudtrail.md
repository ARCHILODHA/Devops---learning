# AWS CloudTrail

## Overview

AWS CloudTrail records API activity and account actions within AWS.

## What It Can Track

Examples include:

- Console activity
- AWS CLI commands
- API calls
- Resource changes
- Identity activity

## Common Uses

- Security auditing
- Compliance
- Troubleshooting
- Investigating unexpected changes

## Example

If an EC2 instance is terminated unexpectedly, CloudTrail can help identify the API activity associated with the termination.

## Best Practice

Enable appropriate CloudTrail logging and protect log storage from unauthorized modification.
