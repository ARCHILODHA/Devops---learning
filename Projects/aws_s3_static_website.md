
# AWS S3 Static Website Deployment

## Overview

This project demonstrates how to deploy a static website using Amazon S3.

The website consists of HTML, CSS and JavaScript files and is hosted directly from an S3 bucket.

## Objectives

- Create an S3 bucket.
- Upload website files.
- Configure static website hosting.
- Configure public access appropriately.
- Access the website through its endpoint.
