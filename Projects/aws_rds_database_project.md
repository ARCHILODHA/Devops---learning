
# AWS RDS Database Project

## Overview

This project demonstrates deploying a relational database using Amazon RDS.

RDS manages database infrastructure such as provisioning, backups, patching and availability.

## Objectives

- Create an RDS database.
- Configure security groups.
- Connect an application to RDS.
- Create database tables.
- Perform CRUD operations.
