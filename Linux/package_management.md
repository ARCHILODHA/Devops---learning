
# Linux Package Management

## Introduction
Package managers install, update, configure and remove software on Linux systems.

## Popular Package Managers

| Package Manager | Distribution |
|---|---|
| APT | Ubuntu, Debian |
| DNF | Fedora, RHEL-based systems |
| YUM | Older RHEL-based systems |
| Pacman | Arch Linux |

## APT Commands
